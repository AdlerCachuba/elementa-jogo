# Elementa · versão jogável

Jogue no navegador: **https://adlercachuba.github.io/elementa-jogo/**

Jogo de ação com os quatro elementos: misture Fogo, Água, Terra e Ar para descobrir magias, atravesse dez capítulos e enfrente a Arena.

**No iPhone:** abra o link no Safari, toque em Compartilhar e depois em **Adicionar à Tela de Início**. O jogo ganha ícone, abre em tela cheia e funciona sem internet depois da primeira visita.

**No Android e no computador:** basta abrir o link no navegador.

Este repositório tem só a versão publicada do jogo. O progresso fica salvo no próprio aparelho.
